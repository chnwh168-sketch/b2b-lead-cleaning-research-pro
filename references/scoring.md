# 独立评分与销售机会

产品证据 P1–P4、业务关系、客户价值、跟进优先级、销售阶段、CRM 纳入决定分别存储。A-直接匹配不自动映射 Match_Grade=A；低价值或 C 不自动排除。

Match_Grade 的评估维度为产品/业务契合50%、采购/渠道能力30%、经营实力20%，作为判断权重，缺失信息不赋零再制造伪精确分数。
- A：主体已闭合、高契合且有采购/渠道和经营实力证据，如重复采购、成熟经销租赁、库存售后、OEM 或稳定项目需求。证据账本需覆盖两类实力。
- B：主体真实相关但采购/规模证据有限，普通用户/承包商或明确项目采购。主体未闭合但联系方式真实、明确购买意图和具体参数/数量/行为时可保守 B，同时 Customer_Type=未确认、Eligibility=Manual Review。
- C：契合弱、外围机会、高风险，或同行制造商缺乏外购/OEM/补线机会。
- -None-：信息不足，不能判断。缺网站、粉丝少、一次问价均不能独自决定等级。

Lead_Tag：实时强 RFQ/报价周期为重点跟进；无即时触发的 A 可周跟进；普通相关 B 一般跟进；较旧较弱但仍相关可月跟进；明确无机会无需跟进。High/Medium/Low 与标签分别解释，不强制一一对应。
Negotiation_Stage：用实际发生的最远事件，报价请求不等于报价已发。目录与公司资料属于并行沟通材料，不仅凭枚举位置覆盖历史；PI、正式报价等事件需证据。

推荐1–5个具体产品，按明确询盘→近期采购→当前销售/租赁且可补线/第二供应商/OEM→强应用需求排序。不创造吨位、功率、型号。已有成熟品牌优先寻找补线、价位差、备件、OEM，避免未经依据建议替换供应商。建议包含一项下一动作和最少待确认问题，不自动发送。
